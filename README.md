# cubemart-relay

Fixed-URL relay for the Cube Mart MCP connector. claude.ai always calls `https://<site>.netlify.app/mcp/<CONNECTOR_SECRET>`;
the relay forwards to whatever Cloudflare quick-tunnel address the work PC registered with "Cube Mart ON".
When Cube Mart is OFF, the relay answers by itself so Claude says "Cube Mart is off - turn it on" instead of erroring.

Functions: `/mcp/:key` (forward), `/register` (PC only, x-register-token), `/status` (on/off, no secrets).
Environment variables (Netlify, scope Functions, mark as secret): `CONNECTOR_SECRET`, `PC_SECRET`, `REGISTER_TOKEN`
- generated by `Cube Mart RELAY SETUP` on the work PC. Store: Netlify Blobs `cubemart` (keys: tunnel, cache_initialize, cache_tools_list).
Limit: Netlify sync functions stop at ~10 s; the relay returns a clean "took too long" message at 9.5 s.
No data is stored on Netlify except the current tunnel address and the cached tool list.
